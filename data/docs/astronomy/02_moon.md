# 月球的自转、地貌与水冰

月球是地球的天然卫星，平均距离地球约三十八万四千四百千米，半径约一千七百四十千米。月球绕地球公转，同时也绕自身轴线自转。它的自转周期与公转周期相同，约为二十七个地球日，这种状态称为同步自转。因此，从地球上通常看到的是月球的同一个半球，而不是月球完全不自转。

月球背面并不是永远没有阳光的区域。随着月球绕地球运行，月球各处会轮流经历白昼和黑夜。从地球看到的月相变化，源于太阳照亮的月面部分与观察方向不断变化。满月时，面向地球的月面基本被太阳照亮；新月时，面向地球的一面主要处于夜晚。由于地球也在绕太阳运动，月相重复所需时间比月球绕地球公转一周更长。

月球可能形成于早期地球与一个火星大小天体的巨大碰撞。碰撞产生的碎屑逐渐聚集成为月球。新形成的月球曾处于熔融状态，后来逐渐冷却结晶，形成月壳。月球内部具有核心、月幔和月壳，其核心相对于整个月球而言较小。

月球大气极其稀薄，难以阻挡陨石等物体撞击表面，因此月面保留着大量撞击坑。长期撞击将岩石破碎成大小不同的碎屑和细粉，形成覆盖月面的大部分月壤。月面较明亮的区域通常被称为高地；较暗的月海是古代熔岩填充撞击盆地形成的区域，并不是真正装满液态水的海洋。

探测发现月球存在水冰，较高浓度的水冰分布在极区黑暗的陨石坑中。这些发现对未来月球探测具有重要意义。现有探测没有发现月球自身存在生命的证据。阿波罗任务带回的月球岩石和土壤样品，则为研究月球形成及早期地质历史提供了直接材料。
