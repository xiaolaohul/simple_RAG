# 水循环与水的储存和迁移

水循环描述水在地球及大气中持续移动，并在液态、固态和水汽之间转换的过程。常见的蒸发、凝结、降水示意图只是一种简化表达，真实的水循环包括多种储存位置和迁移路径。海洋、湖泊、河流、土壤、地下含水层、冰川、积雪和大气，都可以是水的储存库。水在这些储存库之间的移动称为通量。

蒸发是液态水变成水汽的过程。海洋、湖泊、地面积水以及下落的雨滴，都可以发生蒸发，能量可以来自太阳或周围环境。植物通过根系吸收的部分水分，会以水汽形式从叶片离开，这一过程称为蒸腾。蒸发和蒸腾共同把地表及植物中的水输送到大气，而不只是海洋水才能进入大气。

当水汽凝结成小水滴时，可以形成云或地表露水。降水把大气中的水以雨、雪等形式带回地表。到达地面的水可能沿地表流动，形成径流并进入河流和湖泊；也可能下渗到土壤中，继续向更深处渗透，补充地下水。地下水能够沿地下通道移动，因此水并不总是通过地表河流返回其他储存库。

水也会以冰雪形式储存。冻结把液态水转为固态，融化则使冰雪重新变为液态；升华可使固态水直接成为水汽，凝华则是相反的状态变化。海洋储存着地球绝大部分水，淡水只是其中较小的一部分，而淡水又分布在冰雪、地下和地表等不同位置。

水循环与天气、气候和生态系统相互联系。较暖的空气通常会促进蒸发，并能在达到饱和前容纳更多水汽，这使降水时间间隔和降水强度可能发生变化。大气水汽还能吸收能量，水汽和温度之间可能形成正反馈。理解水循环，需要同时考虑水在哪里、以何种状态储存，以及通过哪些过程移动，不能只把它看成一条固定的循环路线。
