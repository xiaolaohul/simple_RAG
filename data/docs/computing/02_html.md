# HTML 元素与文档结构

HTML 是超文本标记语言，用来描述网页内容的含义和组织结构。浏览器读取 HTML 文档后，可以识别哪些内容是标题、段落、链接或其他元素。HTML 文档通常保存为扩展名为 html 的文本文件。标记语言通过元素组织内容，网页中的样式和动态交互则可以分别由样式表和脚本配合完成。

一个常见 HTML 元素由开始标签、内容和结束标签构成。例如段落元素用开始标签和结束标签包围一段文字。标签名称说明元素类型，而不是正文的一部分。有些元素是空元素，不像普通段落那样包围一段内容，因此不能机械地认为所有元素都必须有成对的开始与结束标签。

元素可以包含属性，属性为元素提供额外信息。属性通常位于开始标签内，由属性名称和属性值组成。链接元素的目标位置可以通过属性指定。编写多个属性时，需要按语法将它们正确分隔，并注意属性值的引用方式。属性描述元素的信息，而元素内部的文字通常是向用户展示的内容。

HTML 元素之间能够嵌套，但必须正确关闭。后打开的内层元素应先结束，避免标签交叉。清晰的缩进有助于观察嵌套关系，不过缩进只是代码阅读方式，不能替代正确的元素结构。标签不区分大小写，但统一使用小写是保持一致性和可读性的常见做法。

完整文档具有文档类型声明以及 html、head 和 body 等部分。head 保存文档相关的元信息，例如字符编码和页面标题；body 是网页主要内容的容器。浏览器标签页中显示的文档标题，与正文中的标题元素不是同一件事。将页面元信息与正文内容区分开，有助于理解文档的整体结构。

当正文需要直接显示某些在标记语法中有特殊含义的字符时，可以使用字符引用，避免它们被误认为标签的一部分。HTML 还支持注释，用于给源代码添加说明。学习 HTML 时，应同时理解元素、属性、嵌套和文档骨架，再逐渐组合出更复杂的页面。
