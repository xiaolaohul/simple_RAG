# CSS 的规则、样式与应用方式

CSS 是层叠样式表，用于控制网页内容的呈现方式。HTML 主要组织内容及其结构，CSS 则描述这些内容应当如何显示，例如文字颜色、字体大小、间距和布局。即使网页没有作者编写的样式表，浏览器通常也会使用内置的默认样式，使标题、段落和链接等元素保持基本可读性。

一条基本 CSS 规则由选择器和声明块构成。选择器用于指出规则将作用于哪些元素；声明块放在花括号中，里面可以包含多条声明。每条声明通常由属性和值组成，二者之间用冒号分隔，不同声明之间用分号分隔。属性说明要改变的表现特征，值说明该特征应当采用的具体设置。

例如，可以用段落选择器选中页面中的段落，再通过颜色属性改变文字颜色，通过背景颜色属性改变背景。相同的规则能够作用于多个被选中的元素，因此不必逐个修改所有段落。理解选择器与声明的分工，有助于区分规则没有匹配目标和属性值设置不合适这两类问题。

CSS 可以通过外部样式表、内部样式表或行内样式等方式应用到 HTML。外部样式表把样式规则保存在独立文件中，由 HTML 文档引用，便于让多个页面共享样式。内部样式表把规则写在文档中的样式元素里。行内样式则直接放在特定元素的样式属性中，作用范围更局部。

浏览器会根据文档结构和适用的样式规则呈现页面，这一过程通常称为渲染。CSS 不仅能够改变文本，还可以创建网格、多列等布局，以及动画等视觉效果。一个页面的结构和呈现可以相互配合：同一份结构化内容，在不同样式规则下能够呈现出不同外观。

CSS 的功能按模块组织，背景与边框、布局、颜色等功能可以分别在相应模块中查阅。学习时应先掌握规则语法和样式应用方式，再理解更复杂的表现效果。浏览器默认样式也属于样式来源，因此在判断某个元素为什么具有特定外观时，应考虑作者样式与默认样式共同参与的情况。
